Google Maps API-sleutel

Voor het maken van routes (kaart, zoeken, Street View) heb je een eigen Google Maps API-sleutel nodig. Zet in de Google Cloud Console de Maps JavaScript API, Places API, Geocoding API en Street View Static API aan, en beperk de sleutel bij voorkeur tot jouw domein.

De sleutel wordt alleen lokaal in je browser opgeslagen (localStorage) en nergens naartoe gestuurd, behalve rechtstreeks naar Google.

Meespelen via een gedeelde link kan ook zonder sleutel (dan zie je geen foto-voorbeelden, alleen namen).

Klik op de kaart of zoek een plek hieronder om een markant punt toe te voegen aan de bingokaart.
